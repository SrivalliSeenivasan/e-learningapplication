# Development of E-Learning Application Using Scrum Method

An agile approach for building a simple and user-friendly E-Learning Application with learning materials, courses, quizzes, and progress tracking developed incrementally across Scrum sprints.

## Problem Statement & Objectives

Managing learning materials, course modules, quizzes, and student progress manually or in disconnected tools can be slow and difficult to track. The objective of this project is to develop a simple and user-friendly E-Learning Application that provides learning materials, courses, quizzes, and progress tracking through an iterative Scrum-based development process.

## Features / Modules Implemented

* **Sprint 1:** User Registration & Login, Course Management, and Profile Management.
* **Sprint 2:** Video/Document Lessons, Search & Categories, and Course Enrollment.
* **Sprint 3:** Online Quizzes, Scores & Results, and Progress Tracking.
* **Sprint 4:** Notifications, Reports, and UI Improvements.

## Technology Stack & Tools Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Python
* **Database:** MongoDB
* **Version Control & Project Management:** Git, GitHub, Scrum
